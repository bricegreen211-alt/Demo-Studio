How the call gets placed

Call posts straight to the Voice Gateway Calls API, so the phone rings without the flow doing anything. Your flow only has to handle the call once it connects — that is what Application SID selects. Every value here comes from the VG Self-Service Portal.

Call POSTs the contact to your Agent flow's REST endpoint and the flow places the call itself (see the README for the payload it receives). Posting here runs the flow as a text conversation — if it answers with your call script instead of ringing a phone, the flow matched its branch but never asked Voice Gateway to dial.

Browser extension

This is what puts your demo on the customer's website.

Checking…
1

Open your browser's extensions page

Copy this, paste it into the address bar, and press Enter.

chrome://extensions Using Edge? Copy edge://extensions instead.
2

Turn on “Developer mode”

It's the switch in the top-right of that page. This is the normal way to install an in-house tool that isn't in the Chrome Web Store.

3

Click “Load unpacked”, then choose this folder

A file window opens. Paste the path below into it, or click Show me the folder and drag it in.

4

Pin it to your toolbar

Click the puzzle-piece icon next to the address bar, then the pin next to NiCE Cognigy Demo Studio, so it's always one click away.

5

Turn on “Show demos” when you want to present

Click the extension icon and flip the switch. It starts off on purpose — demos only appear when you turn it on, so they never surprise you in other tabs.

Updating the extension later

When someone ships a change, the extension doesn't update itself. Two steps:

  1. Get the new files — usually git pull in the project folder, or re-download it from your team's link.
  2. Go back to the extensions page and click Reload (the ↻ icon) on the Demo Studio card, then refresh the tab you're testing.

Only changes inside the extension folder need this. New demos, template updates and Studio changes appear on their own.

Claude Plug-in

Once you have a real Agent, Flow, or Endpoint, Claude can create or update a demo and a Remote Control gateway for you — in Claude Code or the Claude desktop app, from any project.

Checking…
1

Already set up, in two pieces

npm install connects this project to both Claude Code and the Claude desktop app — that's the light above. It also installs a skill, a set of instructions at that's what actually teaches Claude when and how to use the connection — without it, Claude has the tools available but no reason to reach for them. Both happen together; neither needs anything from you.

2

Just ask

Once you have a real Agent, Flow, or Endpoint, tell Claude to set up a demo (or a Remote Control gateway) for it, in whatever project or conversation you're already in.

3

If the light above isn't green

Paste this into a terminal from this project's folder — it reconnects Claude Code, the Claude desktop app, and the skill, all together, and is safe to run any time (after moving this folder, for instance):

npm run mcp:register

Restart the Claude desktop app afterward if it was already open.
